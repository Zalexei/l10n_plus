# Changelog

## 0.2.0

**The whole CLDR plural table.** The curated forty language table is replaced
by all 222 cardinal and 107 ordinal languages CLDR 48 publishes, generated by
`tool/update_cldr_plural_rules.dart` and checked against CLDR's own `@integer`
and `@decimal` samples as well as against `package:intl`. Adding a locale to a
project no longer stops at the rule table. Two CLDR subtleties are now compiled
in: a range matches integer values only, and the compact exponent `e` is
resolved at generation time.

* **Fixed: colliding type names generated a file that did not compile.**
  `auth.login` beside `auth_login` both became `$AuthLogin`, with no
  diagnostic. Every top level name is now claimed in one registry, and a
  collision is `type_name_collision` naming both keys.
* **Fixed: `=1` was reported as not covering `one`.** English defines `one` as
  one exact value, so an explicit `=1` branch renders all of it — the shape
  every ARB bundle exported from `gen_l10n` has. Ranges are not attempted and
  `offset:` disables the check.
* **Fixed: `dart analyze` was wrong about English ordinals.** CLDR writes them
  over `n`, not `i`, so `1.5` is `other` rather than `one`.
* **New: `ignore_diagnostics`.** A list of warning codes not to report. Errors
  cannot be listed, an unknown code is reported rather than accepted, and the
  suppressed count is always printed.
* **New: `extra_keys: error | warn`.** At `warn`, a key the base locale does
  not have is reported and left out of generation, for teams whose
  translations arrive through a TMS.
* **New: the format names `gen_l10n` writes.** `decimalPattern`,
  `percentPattern` and `scientificPattern` are accepted as spellings of
  `decimal`, `percent` and `scientific`, in messages and in ARB, and share one
  generated formatter with them. `compactCurrency` and `compactSimpleCurrency`
  are new styles; so is `decimalPercentPattern`, which takes `decimalDigits` —
  the first option that is not about money.
* **New: a date formatted before its symbols are loaded names the fix.** Every
  `DateFormat` is built through a generated helper that turns intl's
  `LocaleDataException` into an error naming
  `initialize<Class>Formatting()`.
* **Better: an unquoted `{` in YAML** is answered with a diagnostic saying to
  quote the message, instead of "Expected a key while parsing a block
  mapping".
* **Better: `unknown_plural_language`** names the CLDR release and the count
  instead of listing two hundred languages, and says when a language has
  cardinal rules but no ordinal ones.

## 0.1.0

First release.

**Formats.** JSON with nested keys, ARB (`@@locale`, `@key` metadata, dotted
keys) and YAML. A locale may be spread over any number of files, in any mix of
formats; `file_pattern` says where the locale sits in the path and whether the
file name becomes a namespace.

**ICU.** `{placeholder}`, `plural` with `=N`, CLDR categories and `offset:`,
`select`, `selectordinal`, `#`, arbitrary nesting and apostrophe quoting. CLDR
plural and ordinal rules are inlined per locale from a curated table; an
unknown language is reported rather than given English rules.

**Numbers and dates.** Named styles and `DateFormat` skeletons, explicit
currency codes (`{n, number, currency:USD}`), `simpleCurrency`, and ARB's
`symbol` and `decimalDigits`. `package:intl` is imported only by generated
files that actually format something, and `format_plural_numbers` decides
whether `#` is formatted.

**Validation.** Every locale is checked against the base locale, which is the
API contract. `fill_missing_from_base` lets a locale be incomplete, rendering
untranslated messages exactly as the base locale renders them.

**Output.** A typed nested API over a `const` object graph, deterministic byte
for byte, `dart_style` formatted, and analyzer-clean in a consumer's project.
`file_per_locale` splits it into one `part` per locale.

**CLI.** `generate`, `analyze` and `unused`, all with diagnostics carrying
file, line, column, key, and what was expected versus found.
